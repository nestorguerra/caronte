legal 02/02

datos tratados

private

que datos se tratan

Identificador de sesion, token publico, consentimiento, estado de pago simulado, voz capturada por el navegador, transcripcion, respuestas a las 21 preguntas, manuscrito, PDF, eventos tecnicos, estado de revision y decisiones de back office.

proveedores

Subencargados tecnicos previstos: Supabase para backend, base de datos y storage privado; ElevenLabs para sintesis de voz; OpenAI para transcripcion y redaccion; Anthropic para revision editorial; proveedor de pago en EUR cuando se active checkout real; Lulu para impresion y envio cuando se active fulfillment. En esta beta no se llama a Lulu ni a la pasarela real.

finalidad

Crear tu libro, generar el PDF, revisar calidad, bloquear el envio hasta aprobacion interna, detectar errores P0 y operar la beta privada.

retencion

Retencion operativa actual: audio hasta 7 dias; respuestas, mapas, manuscritos y PDFs hasta 30 dias; eventos tecnicos hasta 90 dias; auditoria admin hasta 365 dias con minimizacion posterior. El sistema tiene politicas de TTL y accion de retencion para purgar datos caducados.

borrado

Tienes derecho de exportacion y derecho de borrado. Puedes pedir borrado operativo indicando tu identificador de sesion o el contexto suficiente para localizarla. El back office incluye export RGPD, borrado de sesion y limpieza de storage privado asociado.

seguridad

Las claves de proveedores no se exponen en el navegador. El PDF no se libera al cliente hasta aprobacion manual. Se guardan senales anti-abuso en formato hash, no la IP cruda. El hosting preparado para produccion incluye CSP, bloqueo de iframes, politica de permisos y referrer minimo.
