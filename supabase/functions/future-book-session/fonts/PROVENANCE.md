# Crimson Text

Unmodified TTF assets from the Crimson upstream repository:
https://github.com/googlefonts/Crimson/tree/4f1458ae64c6c0d9c5fdfbf5095c7fabe0fa063f

Paths: `fonts/ttf/CrimsonText-{Regular,Bold,Italic}.ttf`.
The accompanying `OFL.txt` is copied from that same fixed commit. SIL OFL 1.1
allows bundling and embedding. Keep the license with the font assets.

SHA-256 hashes are enforced by `caronte-print-fonts.mjs` before rendering.
These are public font assets, not participant data or paid font files.
